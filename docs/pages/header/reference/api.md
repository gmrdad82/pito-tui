[API reference](../../../api/pito_tui/header/index.html). This page lists the whole
public surface in one place.

`Header`, `NavBar` and `Breadcrumb` are ratatui widgets, drawn by value or by
reference with `frame.render_widget`.

`Key`, `Action`, `Step`, `Drill` and `NavKeys` are `#[non_exhaustive]`: match
them with a wildcard arm, and build a `NavKeys` from `HEY` or `NONE` and its
methods, so a later release can add to them in a minor version.

The header reads no files, writes none and prints nothing; its only contract
is this API. Each guide shows a part of it at work:
[groups and sections](../../guides/groups-and-sections/),
[keys](../../guides/keys/), [fitting](../../guides/fit/),
[drill-in](../../guides/drill-in/), [rows](../../guides/rows/),
[styled sections](../../guides/styled-sections/) and
[clicks](../../guides/clicks/).
